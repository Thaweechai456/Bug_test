## 📋 องค์ประกอบฟอร์ม (Form Components)
อ้างอิงและพัฒนาเพิ่มเติมจาก Realbugz Task Form:
1. **รหัส-ชื่อ-สกุล นักศึกษา (ภาษาไทย)**: แสดงที่แถบ Header ด้านบน (กดปุ่มแก้ไขได้ทันที)
2. **ข้อมูลส่วนตัว**: ชื่อนามสกุล, อีเมล, เบอร์โทรศัพท์, วันเดือนปีเกิด, ระดับประสบการณ์
3. **ตำแหน่งและความต้องการ**: ตำแหน่งงานที่ต้องการ, เงินเดือนที่คาดหวัง, รูปแบบการทำงาน (Remote / Hybrid / Onsite), ช่องทางการติดต่อสะดวกที่สุด
4. **เอกสารและเงื่อนไข**: Drag & Drop อัปโหลดไฟล์ (Resume / ID), กล่องข้อความเพิ่มเติม, ช่องกดยอมรับข้อกำหนดและเงื่อนไข
5. **ปุ่มควบคุม**: ปุ่มล้างข้อมูล (Reset) และปุ่มส่งใบสมัคร (Submit) พร้อม Modal Popup สรุปข้อมูลเมื่อสำเร็จ
6. **เฉลยบัคท้ายเว็บ (Accordion)**: ส่วนพับเปิด-ปิดสำหรับอาจารย์หรือเพื่อนเพื่อดูเฉลยจุดบัค

## 🐛 เฉลยตำแหน่ง BUG 2 ตำแหน่ง (สำหรับผู้พัฒนาและอาจารย์)

| ลำดับ | จุดที่เกิด Bug | ฟังก์ชัน / โค้ดที่เกี่ยวข้อง | พฤติกรรมที่ผิดพลาด (Bug Behavior) |
| :--- | :--- | :--- | :--- |
| **Bug 1** | **Contact Number** (เบอร์โทรศัพท์) | `script.js` -> `validatePhone()` | เบอร์โทรศัพท์มาตรฐานไทยต้องมี **10 หลัก** แต่โค้ดใช้ Regex ตรวจสอบเป็น **9 หลัก** (`/^0[0-9]{8}$/`) <br>➡️ **ผลลัพธ์:** หาก Tester กรอกเบอร์ 10 หลัก (เช่น `0812345678`) ระบบจะแจ้งเตือนว่าผิด แต่ถ้ากรอก 9 หลัก (เช่น `081234567`) ระบบจะอนุญาตให้ผ่าน |
| **Bug 2** | **Terms & Conditions** (กดยอมรับเงื่อนไข) | `script.js` -> `validateTerms()` | ฟอร์มระบุดอกจันสีแดง `*` (Required) แต่ในโค้ดมีการตั้งค่าข้ามการตรวจสอบ (`isBypassValidation = true`) <br>➡️ **ผลลัพธ์:** แม้ผู้ใช้ **ไม่ได้ติ๊กถูก** ยอมรับเงื่อนไข เมื่อกด Submit ระบบก็ยังอนุญาตให้ส่งฟอร์มและบันทึกข้อมูลได้สำเร็จ |
